# Andes Real Estate Investment Analysis

Power BI dashboard project focused on real estate commercial performance, property sales, customer segments, sales channels, time-based analysis, and customer cohort behavior.

## Project Status

This repository contains the approved project notebook and the Power BI dashboard file developed for the analysis.

## Project Overview

This project analyzes the commercial performance of Andes Capital Real Estate through property sales, customer behavior, property characteristics, and sales channels.

## Business Relevance

This project is especially relevant for Business Intelligence and Marketing Data Analytics because it connects real estate transactional data with executive and commercial decision-making.

## Current Files

- `andes-real-estate-project-notebook.ipynb`: approved project notebook with documentation, analytical requirements, dashboard structure, business interpretation, and evaluator feedback
- `andes-real-estate-dashboard.pbix`: Power BI dashboard file with executive overview, commercial analysis, time intelligence, and cohort analysis
